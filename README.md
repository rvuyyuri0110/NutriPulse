# ⚡ Installation


## Navigate to Project

```bash
cd nutripulse
```

## Install Dependencies

```bash
npm install
```

## Configure Environment Variables

Create a `.env` file and add:

```env
GEMINI_API_KEY=your_api_key
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
```

## Run Development Server

```bash
npm run dev
```
